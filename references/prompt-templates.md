# 怪物特摄手办动画提示词模板

## 使用规则

- 只选择与用户任务对应的模板，不强制一次输出全部路径。
- 先替换花括号变量，再删除空字段；不要把占位符留给最终用户。
- 输出规格只继承用户或上游明确值，不自行固定模型、分辨率、画幅、时长、镜头数或帧率。
- 默认生成Q版怪兽手办的微缩后勤空间日常喜剧；只有用户明确要求时才启用战斗／巨大特摄支线。
- 没有外部参考时，按职责调用内置四图：`reference-01-style-anchor.jpg` 负责整体媒介与叙事风格，`reference-02-character-design.jpg` 只负责小怪兽角色设计的整体风格、比例、材质与变化范围，`reference-03-environment.jpg` 负责空间，`reference-04-camera-storyboard.jpg` 负责镜头。角色板中的任何单体都不是身份参考、预设角色或默认阵容；必须根据用户主题重新组合轮廓、体色、服装、表情与道具，示例地点也不自动复刻。
- 图生图先写参考职责和保留项；视频逐镜头写结束状态与下一镜连续性。

## 常用喜剧动作模块

### 道具连锁滑落

```text
角色先在稳定中近景中执行例行工作；一个收纳箱、雨伞架或同类道具失去平衡，角色用一个明确的后仰或伸手姿势反应。滑落物按可读方向逐级移动，邻近小物只产生有限反馈；爆点瞬间加入少量指向运动中心的漫画速度线，随后立即退出并停在残局姿势。
```

### 提示灯触发僵住

```text
小面积指示灯或提示音先进入画面，角色的眼睛或头部转向触发物，再用一次姿势跳变从工作状态切到全身僵住。镜头从中近景短促推近到反应特写，背景与家具保持稳定；在特写上留出短暂停顿，让灯声、眼神和塑料关节轻响完成笑点。
```

### 桌面低机位追赶

```text
滚动或滑动的小物从桌面前景掠过，摄影机保持贴近桌面的超低机位；角色粗短手臂伸向前景，身体重心随关节分段前移，脚底或支撑点清楚。小物的运动方向、角色视线和下一镜离场方向必须一致，不使用夸张超广角拉伸。
```

### 狭窄通道奔跑

```text
角色上身前倾，短腿在清楚的离散姿势间快速交替，手臂夸张摆动，脚底每次接触都有塑料重击；采用平视或略低机位的侧向跟拍，让置物架、门框和收纳箱掠过形成速度。只加克制动感模糊和少量速度线，最后交付明确的离场方向。
```

### 固定远景停顿收尾

```text
动作爆点后切到固定远景，让角色被倾斜道具、狭窄空间或失败结果短暂困住；摄影机和背景完全稳定，只保留一处微小姿势或道具余动。不给额外解释，在安静停顿中用环境底噪或一声短促塑料拟音结束。
```
